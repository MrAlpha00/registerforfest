Welcome to the official web repository for **Acharya Habba 2026**!
Acharya Habba, launched in 2006, is Bangalore's premier annual college fest known for its diverse social and cultural experiences, featuring talent displays, music, sports, and collaborative events.

## ✨ Features
- **Modern & Dynamic UI**: Built with HTML5, CSS3, React 19 and styled magically using Tailwind CSS.
- **Immersive 3D Experiences**: Powered by React Three Fiber and Drei for interactive WebGL elements.
- **Smooth Animations**: Integrated with Framer Motion and GSAP for buttery smooth user interactions.
- **Interactive Globe**: Featuring Cobe for a stunning interactive globe.
- **Responsive Design**: Flawlessly adapts to any screen size, ensuring a premium mobile and desktop experience.
- **Advanced Navigation & Displays**: Utilizing Swiper, Embla Carousel, and Lenis for smooth scrolling and engaging content display.

## 🛠️ Technology Stack

- **Frontend Framework**: React 19 + Vite
- **Styling**: Tailwind CSS, PostCSS, clsx, tailwind-merge
- **Animations**: Framer Motion, GSAP, Lenis (Smooth Scrolling)
- **3D & Canvas**: @react-three/fiber, @react-three/drei, ogl, cobe
- **Icons**: Lucide React, React Icons
- **Routing**: React Router DOM
- **Forms & State**: React Hook Form
- **Data Visualization**: Recharts

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

You need to have Node.js and npm (or yarn/bun) installed on your machine.
- [Node.js](https://nodejs.org/en/download/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mralpha00/registerforfest.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd registerforfest
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to the local Vite preview port (usually `http://localhost:5173`) to see the application in action.

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Runs the app in development mode.
- `npm run build`: Builds the app for production to the `dist` folder.
- `npm run lint`: Lints the codebase using ESLint.
- `npm run preview`: Locally preview the production build.
